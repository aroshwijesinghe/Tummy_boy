# Tummy_boy

Simple Flutter mobile app with one feature: count how many pushups are done.

## What It Does

- Shows current pushup count.
- `Add Pushup` button increments the count.
- `Reset` button sets the count back to zero.

## Main Files

- `lib/main.dart`: App entry point.
- `lib/app.dart`: Single-screen pushup counter UI and state.
- `pubspec.yaml`: Minimal Flutter dependencies.

## Run

```bash
flutter pub get
flutter run
```
